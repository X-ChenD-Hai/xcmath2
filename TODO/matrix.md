# 矩阵操作

## 矩阵基础

- [x] `transpose(m)` - 矩阵转置
- [x] `determinant(m)` - 行列式 (2x2, 3x3, 4x4)
- [x] `inverse(m)` - 矩阵求逆
- [x] `trace(m)` - 矩阵的迹
- [x] `outer_product(v1, v2)` - 向量外积 (生成矩阵)

## 矩阵运算

- [x] `mat * mat` - 矩阵乘法
- [x] `mat * vec` - 矩阵与向量乘法
- [x] `mat + mat` / `mat - mat` - 矩阵加减法
- [x] `mat * scalar` - 矩阵标量乘法
