# 矩阵操作

## 矩阵基础

- [ ] `transpose(m)` - 矩阵转置
- [ ] `determinant(m)` - 行列式 (2x2, 3x3, 4x4)
- [ ] `inverse(m)` - 矩阵求逆
- [ ] `trace(m)` - 矩阵的迹
- [ ] `outer_product(v1, v2)` - 向量外积 (生成矩阵)

## 矩阵运算

- [ ] `mat * mat` - 矩阵乘法
- [ ] `mat * vec` - 矩阵与向量乘法
- [ ] `mat + mat` / `mat - mat` - 矩阵加减法
- [ ] `mat * scalar` - 矩阵标量乘法
