# 几何工具

## 碰撞检测辅助

- [ ] `face_forward(n, i, nref)` - 面向前方法向量
- [ ] `triangle_normal(v0, v1, v2)` - 三角形法向量
- [ ] `barycentric(p, a, b, c)` - 重心坐标

## 包围盒 (AABB)

- [ ] `aabb` 类型 - 轴对齐包围盒
- [ ] `aabb_contains(box, point)` - 点包含测试
- [ ] `aabb_intersects(box1, box2)` - 包围盒相交测试
- [ ] `aabb_expand(box, point)` - 扩展包围盒
